# Containment matrix: the sandbox, measured

Generated by `tests/security/containment/matrix.py`; do not edit. Each cell is what a benign probe managed to do when run through the real `replicator.build.sandbox.Sandbox` in that execution mode. `SECURITY.md` copies its status words from here; `tests/security/containment/test_matrix.py` fails on any claimed cell that is not PASS.

- **PASS**: the probe was blocked, as claimed
- **FAIL**: the probe succeeded where the sandbox claims to block it (a finding)
- **N-A**: not enforced in this mode by design; the reason is in the cell, the outcome is still recorded
- **ERROR**: the probe could not be run or its verdict could not be read (a failure)
- **not run**: this mode has not been measured on any machine yet
